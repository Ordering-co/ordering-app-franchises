# Ordering Franchise App

Open the customer app for your chosen Ordering franchise and see your first edit live.

## 1. Paste this into your coding agent

```text
Get https://github.com/Ordering-co/ordering-app-franchises.git and read setup.md. Follow its instructions to configure my Ordering project and explicitly chosen franchise, open the app locally, and verify my first visible edit through Fast Refresh.
```

## 2. Confirm your project and franchise

Confirm your Ordering project and explicitly tell the agent which franchise to use. You can provide the project code if you do not have a connection.

## 3. Open your app

Check that the preview shows your project and chosen franchise. Ask the agent to make one small visible edit and watch it update live.

Local iOS preview needs macOS and Xcode; Android development needs Android Studio and Java.
